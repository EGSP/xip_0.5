# xip 0.5

Минимальный агентский цикл поверх Yandex AI Studio через OpenAI-совместимый API.
Учебный стенд: показывает, как модель запрашивает вызовы инструментов и что происходит дальше.
Замысел и границы этапа — в [ПЛАН.md](ПЛАН.md).

## Запуск

```bash
cp .env.example .env
npm install
npm run check
npm start
```

`npm run check` проверяет настройку отдельно от интерфейса: получает IAM-токен и делает одно
обращение к модели. Запускать его первым, потому что сообщения об ошибках в нём не затираются
перерисовкой Ink.

## Команды

| Команда | Что делает |
|---|---|
| `npm start` | интерактивный интерфейс на Ink; требуется настоящий терминал |
| `npm run check` | проверка IAM-токена и доступности модели |
| `npm run once -- "<запрос>"` | один ход без интерфейса, лента событий обычным выводом |
| `npm run typecheck` | проверка типов |

В интерфейсе: `Esc` — прервать текущий ход, `/exit` — выход.

## Конфигурация

Все переменные описаны в [.env.example](.env.example). Обязательна `YANDEX_MODEL` — без неё
программа не стартует и печатает перечень незаполненных значений.

Аутентификация — IAM-токен, двумя способами: готовый токен из `yc iam create-token`
(живёт около 12 часов) либо ключ сервисного аккаунта, из которого программа сама подписывает
JWT и обменивает его на IAM-токен, обновляя по мере истечения. Второй способ основной;
сервисному аккаунту нужна роль `ai.languageModels.user` на каталоге.

## Устройство

| Файл | Назначение |
|---|---|
| `src/agent-loop.ts` | цикл: обращение к модели → исполнение вызовов → повтор |
| `src/model-client.ts` | клиент OpenAI-совместимого API, авторизация заголовком на каждый запрос |
| `src/yandex-auth.ts` | подпись JWT и обмен на IAM-токен, кеш с заблаговременным перевыпуском |
| `src/tools.ts` | описания инструментов для модели и их исполнение |
| `src/session-log.ts` | журнал событий сессии |
| `src/config.ts` | чтение и проверка конфигурации |
| `src/ui/` | интерфейс на Ink |

## Отступления от плана

1. **Прерывание хода по `Esc`.** План этапа его исключал, но при интерфейсе на Ink это
   десять строк (`AbortController`, сигнал передаётся в запрос к модели), а без него
   долгий ход нельзя остановить, не завершая программу.
2. **`run-once.ts`.** Понадобился, чтобы прогонять цикл там, где интерактивный ввод
   недоступен.

## Что проверено

Оба сценария отработаны на модели `qwen3.6-35b-a3b/latest`.

**Цепочка зависимых вызовов.** Запрос «брось два кубика, запиши сумму в заметки и покажи
заметки» дал три вызова подряд (`roll_dice` → `write_note` → `read_notes`) и верный итог.

**Восстановление после отказа инструмента.** При попытке записать четвёртую строку
`write_note` вернул ошибку с указанием вызвать `clear_notes`; модель прочитала текст,
очистила заметки и повторила все три записи. Это подтверждает правило из
`../Исследования архитектуры/Цикл агента/Как устроен цикл.md`: ошибка инструмента —
результат вызова, а не исключение, и её текст должен предписывать, что делать дальше.

## Известное

Через `npm run` обращения иногда завершаются сетевой ошибкой `fetch failed`, тогда как
запуск тем же `npx tsx src/...` проходит. Причина не в коде: в окружении заданы
`HTTP_PROXY`/`HTTPS_PROXY` на локальный порт, и поведение зависит от того, доступен ли
он в момент запуска. Диагностика улучшена — код причины (`ECONNRESET`, `ENOTFOUND`)
теперь печатается вместе с сообщением.
